## 普通形式
我们有一个$sign$函数:
$$sign(x) = \begin{cases}
1,x\ge0\\
-1,x<0\\
\end{cases}$$
在$R^n$空间中任意点到超平面距离为:
$$d = \frac{|w^T x_0 + b|}{\|w\|}$$
这是由超平面方程推导得到的
$$w^T x + b = 0$$
这是超平面方程.其中$w$是超平面法向量,b是截距,x是点位置的向量表示
超平面本质是这个$w$法向量,当我们有一个超平面进行分类,而且这个数据集是可以被超平面分割的.
那么对于被误分类的点$(x_i,y_i)$,有:$$-y_i(w\cdot x_i + b)>0$$
通过这种方式,我们可以构建出损失函数.
$$L(w, b) = - \sum_{x_i \in M} y_i(w \cdot x_i + b)$$
这里的$M$是误分类的点的集合.
既然有了损失函数,那么就可以更新$w$,来得到最终的超平面分类.具体使用梯度下降的方法就可以由误分类点驱动更新模型了.
## 对偶形式
由于本质上感知机模型是由误分类点驱动的,那么最开始的参数是随机的,任意一个点都有可能被误分类,那么本质上是由点与点直接的关系决定了超平面的位置,由此引申出对偶形式.
对偶形式本质是记录一个点被误分类了几次,通过类似投票的方式决定超平面的位置.
